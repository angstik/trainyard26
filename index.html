INSTALLER

Une fois installé, le jeu s'ouvre comme une application
et fonctionne sans connexion.

IPHONE / IPAD
  1. Ouvrez cette page dans Safari
  2. Appuyez sur l'icône Partager (carré avec flèche vers le haut)
  3. Choisissez « Sur l'écran d'accueil »
  4. Confirmez avec Ajouter
ANDROID
  1. Ouvrez cette page dans Chrome
  2. Ouvrez le menu ⋮ en haut à droite
  3. Choisissez « Installer l'application »
ORDINATEUR
  1. Ouvrez cette page dans Chrome ou Edge
  2. Cliquez sur l'icône d'installation dans la barre d'adresse
